# What Happens When You Type Google.com in Your Browser and Press Enter?

This project explores the journey of a web request from a user's browser to a remote server and back.

The objective is to understand and explain the main components involved in modern web infrastructure, including:

* DNS resolution
* TCP/IP communication
* HTTPS and SSL/TLS encryption
* Firewalls
* Load balancers
* Web servers
* Application servers
* Databases

The project includes a technical article and a diagram illustrating how these components interact to deliver a web page when a user visits `https://www.google.com`.

This work was completed as part of the Holberton School Networking curriculum.
